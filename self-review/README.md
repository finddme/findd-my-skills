# self-review

PR 제출 전 정밀 리뷰. 찾은 지적을 **실행으로 검증**하고, 모든 지적을 **원장**에 기록해 끝까지 닫는다. **리뷰 전용**이라 코드를 고치거나 커밋하지 않는다.

> 사람용 소개 문서. 스킬 동작은 `SKILL.md`가 정한다.

## 호출

```
/self-review
```

명시 호출 시에만 동작한다. 시작할 때 리뷰 범위(diff / 전체), 실행 환경, 예산 상한, 결정 기록 위치, 원장 저장 위치를 묻는다.

## 흐름

| 단계 | 내용 |
|---|---|
| P0 기준선 | SHA 고정, 변경 인벤토리, 실행 환경 확보(검증 수준 V0~V4), 테스트 기준선(2회로 flaky 분리) |
| P1 지도 | 타겟 분할(분기점 → 공통 층 + 기능 단위, 위험 순), 경로 × 불변식 매트릭스, 신뢰 경계표 |
| P2 발견 | 타겟 × 검토 축 10개(+ 프로젝트별 추가 축) |
| P3 검증 | 별도 에이전트가 실제 진입점으로 재현. 안전한 불변식은 "검증 OK"로 기록 |
| P4 적대 검증 | 방어 코드를 변형 입력으로 공격 |
| P5 분류·보고 | 등급(영향 × 도달성)과 확신도를 따로 매김. 보고 후 다음 단계를 묻는다 |
| P6 인계 | **사용자가 원할 때만**: 수정은 `/vet-review`, 게시는 `/review-post` |
| P7 제출 전 | 수정 후 HEAD 증분 재실행 + PR 위생 점검 + PR 본문 초안 |

## 원장

리뷰 1회당 마크다운 파일 1개. 항목마다 `### <id>` 블록으로 위치·등급·검토 축·확신도·재현·상태를 적는다. 같은 파일을 `/review-post comment`와 `/vet-review`에 그대로 넘길 수 있다. 형식은 `references/ledger.md`.

## 관련

- `/self-review-light`: 정적 다중 관점 리뷰(가벼운 버전, 수정 루프 포함)
- `/vet-review`: 원장을 받은 리뷰로 읽어 판정·수정
- `/review-post`: 원장에서 고른 항목을 PR에 게시
