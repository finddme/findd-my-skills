# tighten-prose

이미 쓴 한국어 글(문서, 채팅에 올릴 내용)을 가독성과 전달 효율 위주로 다듬는 스킬. 코드는 대상이 아니다.

> 사람용 소개 문서. 스킬 동작은 `SKILL.md`가 정한다.

## 호출

```
/tighten-prose
```

명시 호출 시에만 동작한다.

## 무엇을 바꾸나

| 구분 | 규칙 요약 |
|---|---|
| 문체 | 명사형(개조식) 종결 우선, 음슴체 금지, em-dash 금지, 연결어미 뒤 쉼표 지양, 비유 대신 정확한 용어 |
| 톤 | 쉽게 쓰되 전문 용어·함수명·수치는 유지. 추상 설명보다 실제 값 예시 |
| 구조 | 긴 문장은 하위 불릿으로, 비교는 표로, 반복 표현 정리 |
| 사실성 | 코드 기반 문서는 코드·실행 로그로 확인한 사실만 |

다이어그램 규칙은 `diagram-design` 스킬을 따른다.
