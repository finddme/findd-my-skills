# self-review-light

내 브랜치·PR의 변경을 여러 관점으로 리뷰하고, 확정된 이슈를 문서 우선으로 고치는 스킬.

> 사람용 소개 문서. 스킬 동작은 `SKILL.md`가 정한다.

## 호출

```
/self-review-light
```

명시 호출 시에만 동작한다. 가벼운 확인은 1차만, "철저히"는 3-pass 전체를 돈다.

## 흐름

| 단계 | 내용 |
|---|---|
| Phase 0 | 범위 확정(기능 diff만 분리) |
| 1차 | 5개 관점 병렬 발견(프로젝트 규칙 / 버그 / 이력 / 이전 PR 코멘트 / 주석 정합) + 신뢰도 채점(80 미만 제외) |
| 2차 | 독립 재검증(`superpowers:requesting-code-review`, 1차 결과 미전달, 실제 테스트 실행) |
| 3차 | 체크리스트 7묶음 병렬 스윕(`references/checklist.md`) |
| 수정 | 방향 확정 → 문서에 계획 → 구현 → 테스트 검증 |

## 관련

- `/self-review`: 실행 검증·원장까지 하는 정밀 리뷰(리뷰 전용, 코드 수정 없음)
- `/vet-review`: 받은 리뷰를 판정하고 반영
