# poc-run

PoC를 처음부터 끝까지 이끄는 오케스트레이터. 모델 성능 한 번 재는 작은 PoC부터 설계 → 단계별 실험 → 파이프라인 구축 → e2e 측정 → 엣지 케이스 보강까지 규모에 맞춰 진행한다.

> 사람용 소개 문서. 스킬 동작은 `SKILL.md`가 정한다.

## 호출

```
/poc-run
```

명시 호출 시에만 동작한다. 시작할 때 PoC 규모와 목표를 사용자에게 묻는다.

## 핵심 원칙

- **자동 진행 금지**: 단계마다 사용자 승인 후 시작. 끝나면 다음 선택지를 추천하고 기다린다.
- **하위 스킬은 요청 시에만** 실행.
- **평가 게이트**(모든 측정·결정에 적용): 성공 기준 선확정, holdout 분리, 비결정 시스템 N회 반복, 비용·지연 상한, in-sample/held-out 분리 보고, 만성 실패 카탈로그, 실패 계층 귀속, 회귀 확인, 추정보다 실측, 비교군 선정의.

## 흐름

| 단계 | 내용 |
|---|---|
| 0 | 스펙·목업·요구사항 입수 |
| 1 | 최신 동향 조사 |
| 2 | 설계(단계 분해, 단계별 통과 조건) |
| 3 | 데이터셋 준비(없으면 수집·생성) |
| 4 | 단계별 실험 |
| 5 | 파이프라인 구축 |
| 6 | e2e 측정 |
| 7 | 엣지 케이스 보강 |
| 8 | 완료 판정 |
| 9 | 운영 코드로 이관 |

모든 단계는 사용자가 요청할 때만 들어간다.
