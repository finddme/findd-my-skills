# findd-my-skills

- poc-run
    PoC를 처음부터 끝까지 이끄는 오케스트레이터. 모델 성능 한 번 재는 작은 PoC부터 설계 → 단계별 실험 → 파이프라인 구축 → e2e 측정 → 엣지 케이스 보강까지 규모에 맞춰 진행

- review-post
    리뷰 결과를 GitHub PR에 게시하는 스킬. **무엇을 올릴지는 항상 사용자가 정하고**, 게시 전에 미리보기를 보여 주고 승인을 받는다.

- self-review
    PR 제출 전 정밀 리뷰. 찾은 지적을 **실행으로 검증**하고, 모든 지적을 **원장**에 기록해 끝까지 닫는다. **리뷰 전용**이라 코드를 고치거나 커밋하지 않는다.

- self-review-light
    내 브랜치·PR의 변경을 여러 관점으로 리뷰하고, 확정된 이슈를 문서 우선으로 고치는 스킬.

- tighten-prose
    이미 쓴 한국어 글(문서, 채팅에 올릴 내용)을 가독성과 전달 효율 위주로 다듬는 스킬.

- vet-review
 **받은 코드리뷰**(사람·도구·CI)가 맞는지 실제 코드로 판정하고, 타당한 것만 문서로 계획해 고치는 스킬.
