# vet-review

**받은 코드리뷰**(사람·도구·CI)가 맞는지 실제 코드로 판정하고, 타당한 것만 문서로 계획해 고치는 스킬.

> 사람용 소개 문서. 스킬 동작은 `SKILL.md`가 정한다.

## 호출

```
/vet-review
```

명시 호출 시에만 동작한다. 입력은 PR 리뷰 링크, 리뷰 본문, 또는 `/self-review` 원장.

## 흐름

| 단계 | 내용 |
|---|---|
| 1 읽기·분류 | 블로킹 / 개선 / 질문 / 불명확. 불명확하면 먼저 묻는다 |
| 2 독립 판정 | 코드 직접 읽기 + `superpowers:requesting-code-review` + 결정적 검사기(bandit, pyright 등) |
| 3 의도·이력 | 참고 문서 위치를 묻고 git 이력 확인. "이미 고침"은 리뷰 작성 시각과 수정 커밋 시각을 대조 |
| 4 판정 보고 | 타당 / 부분 타당 / 반박 / 이력 확인 필요 / 중복. 재현 표, 결정값 표(근거 유형 포함) |
| 5 항목별 문서 | 리뷰 1건당 파일 1개. 머리에 `리뷰` / `상태` / `커밋` 줄 |
| 6 수정 | 결정값 근거 규칙 → 승인 → 체크리스트대로 TDD 진행 → 커밋 기록 |

## 결정값 근거 규칙 (요약)

수치 결정값에는 근거 유형(도출 / 실측 / 외부 스펙 / 결정 / 추정)을 붙인다. 근거가 없으면 값을 추천하지 않고 측정 계획을 낸다. 리뷰어 예시값은 근거가 아니다.

## 관련

- `/review-post reply`: 처리 커밋을 리뷰 스레드마다 답글로 게시(사용자가 원할 때, 쓸지 먼저 묻는다)
- `/self-review`: 원장을 넘겨받아 판정·수정할 수 있다
- 배경: `superpowers:receiving-code-review`
